# 🧮 سیستم هوشمند محاسبه مالیات

سیستمی مبتنی بر هوش مصنوعی برای استخراج خودکار کد ملی از روی تصویر کارت ملی ایرانی و محاسبه‌ی مالیات شهروندان بر اساس شغل، درآمد سالانه و معافیت‌های مالیاتی.

## ✨ ویژگی‌ها

- 📷 **استخراج خودکار کد ملی** از روی تصویر کارت ملی با استفاده از مدل‌های چندوجهی (Vision) از طریق [OpenRouter](https://openrouter.ai)
- 🔍 **جستجوی شهروند** بر اساس کد ملی و نمایش اطلاعات هویتی و سوابق مالیاتی
- 💰 **محاسبه مالیات پلکانی** بر اساس براکت‌های درآمدی و نرخ مالیات هر شغل
- 🎁 اعمال **معافیت‌های مالیاتی** (معلولیت، سرپرست خانوار، چند فرزندی و ...)
- 🗃️ ذخیره‌سازی اطلاعات در پایگاه‌داده SQLite
- 🖥️ رابط کاربری وب ساده و راست‌چین با [Gradio](https://gradio.app)
- 🔀 مدیریت گردش‌کار پردازش با [LangGraph](https://langchain-ai.github.io/langgraph/)

## 🛠️ تکنولوژی‌های استفاده‌شده

| بخش | ابزار |
|---|---|
| رابط کاربری | Gradio |
| هماهنگ‌سازی فرآیند | LangGraph |
| ارتباط با مدل‌های زبانی | LangChain (`langchain-openai`) |
| ارائه‌دهنده مدل‌های AI | OpenRouter |
| پایگاه‌داده | SQLite |

## 📁 ساختار پروژه

```
project/
├── app.py                 # رابط کاربری Gradio و نقطه ورود برنامه
├── graph.py                # گراف LangGraph برای مدیریت گردش‌کار محاسبه مالیات
├── ocr_service.py          # استخراج کد ملی از تصویر با مدل‌های Vision (OpenRouter)
├── tax_service.py          # منطق محاسبه مالیات و معافیت‌ها
├── database.py             # مدیریت پایگاه‌داده SQLite (ساخت جداول، seed، کوئری‌ها)
├── tax_system.db            # فایل پایگاه‌داده (به‌صورت خودکار ساخته می‌شود)
├── few_shot_examples/       # تصاویر نمونه برای بهبود دقت OCR (few-shot)
├── .env                     # کلیدهای محرمانه 
└── requirements.txt         # وابستگی‌های پایتون
```

## ⚙️ پیش‌نیازها

- Python 3.10 یا بالاتر
- یک حساب کاربری در [OpenRouter.ai](https://openrouter.ai) و یک API Key معتبر

## 🚀 نصب و راه‌اندازی

### ۱. کلون کردن پروژه

```bash
git clone https://github.com/<username>/<repo-name>.git
cd <repo-name>
```

### ۲. ساخت محیط مجازی و نصب وابستگی‌ها

```bash
python -m venv venv
source venv/bin/activate      # در ویندوز: venv\Scripts\activate

pip install -r requirements.txt
```

> اگر فایل `requirements.txt` ندارید، حداقل پکیج‌های زیر لازم است:
> ```bash
> pip install gradio langchain langchain-openai langgraph httpx python-dotenv
> ```

### ۳. تنظیم متغیرهای محیطی

یک فایل `.env` در ریشه‌ی پروژه بسازید و کلید API خود را در آن قرار دهید:

```env
OPENROUTER_API_KEY=your_openrouter_api_key_here
```

### ۴. اجرای برنامه

```bash
python app.py
```

برنامه روی آدرس زیر در دسترس خواهد بود:

```
http://localhost:1689
```

## 📖 نحوه استفاده

### تب «محاسبه مالیات»
1. تصویر کارت ملی را آپلود کنید.
2. روی دکمه «محاسبه مالیات» کلیک کنید.
3. سیستم به‌صورت خودکار کد ملی را از تصویر استخراج، در پایگاه‌داده جستجو و گزارش مالیات را نمایش می‌دهد.

### تب «جستجوی کاربر»
با وارد کردن یک کد ملی ۱۰ رقمی، اطلاعات هویتی شهروند و سوابق مالیاتی او نمایش داده می‌شود.

#### کدهای ملی نمونه برای تست
| کد ملی | نام | شغل |
|---|---|---|
| 1270765108 | علی محمدی | کارمند دولتی |
| 0023456789 | مریم احمدی | پزشک |
| 0034567890 | محمد رضایی | مهندس |
| 0045678901 | زهرا حسینی | بازنشسته |
| 0056789012 | امیر کریمی | آزاد |

## 📊 منطق محاسبه مالیات

- **معافیت پایه:** ۵۰۰ میلیون ریال از درآمد سالانه معاف از مالیات است.
- **مالیات پلکانی:** باقیمانده درآمد بر اساس براکت‌های زیر مشمول مالیات می‌شود:

| سقف درآمد مشمول (ریال) | نرخ |
|---|---|
| تا ۵۰۰ میلیون | ۰٪ |
| تا ۱ میلیارد | ۱۰٪ |
| تا ۱.۵ میلیارد | ۱۵٪ |
| تا ۲ میلیارد | ۲۰٪ |
| بیشتر از ۲ میلیارد | ۲۵٪ |

- **نرخ شغلی:** علاوه بر مالیات پلکانی، نرخ مالیات مخصوص هر شغل نیز اعمال و میانگین دو مقدار به‌عنوان مالیات پایه در نظر گرفته می‌شود.
- **معافیت‌های ویژه:** درصد معافیت‌های فعال شهروند (معلولیت،  چند فرزندی و ...) از مالیات پایه کسر می‌شود (حداکثر تا ۱۰۰٪).

## 🤖 مدل‌های هوش مصنوعی پشتیبانی‌شده (OCR)

- GPT-4o / GPT-4o Mini / GPT-4 Turbo (OpenAI)
- Claude 3.5 Sonnet / Claude 3 Opus (Anthropic)
- Gemini Pro Vision / Gemini 1.5 Pro (Google)
- Llama 3.2 90B Vision (Meta)

## ⚠️ نکات مهم

- برای استفاده از قابلیت OCR، یک `OPENROUTER_API_KEY` معتبر در فایل `.env` الزامی است.
- تصویر کارت ملی باید واضح و خوانا باشد تا استخراج کد ملی با موفقیت انجام شود.
- پایگاه‌داده `tax_system.db` در اولین اجرا به‌صورت خودکار ساخته و با داده‌های نمونه پر می‌شود.
